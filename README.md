# Пригодницька гра — патерн проєктування «Стратегія» (Strategy)

Навчальний проєкт: реалізація поведінкового патерну проєктування **Strategy**
на прикладі системи бою ігрових персонажів, які можуть вільно міняти зброю
під час гри.

## Умова завдання

**Дано:**
- ієрархія класів включає ігрових персонажів і різні типи озброєння;
- кожен персонаж будь-якої миті використовує лише один вид зброї, але може
  вільно міняти зброю під час гри;
- має бути передбачена можливість додавати нових персонажів, види зброї та
  інші властивості без глибокого редагування вже написаного коду.

**Завдання:**
1. Побудувати діаграму класів патерну «Стратегія» для описаної предметної області.
2. Реалізувати програму на основі цього патерну (довільною мовою програмування).
3. Оформити звіт за встановленими правилами.

## Патерн Strategy — суть рішення

Замість того, щоб «зашивати» спосіб атаки прямо в клас персонажа (через
`if/else` чи `switch`), поведінка атаки виноситься в окремі класи-стратегії,
що реалізують спільний інтерфейс `IWeaponBehavior`. Персонаж лише **тримає
посилання** на поточну стратегію і делегує їй виконання дії. Це дозволяє:

- змінювати зброю персонажа в будь-який момент через `SetWeapon()`;
- додавати нові види зброї, просто створивши новий клас, що реалізує
  `IWeaponBehavior` — без змін у класах персонажів;
- додавати нових персонажів, успадкувавши абстрактний клас `Character` — без
  змін у класах зброї.

## Структура класів

| Роль | Клас | Тип |
|---|---|---|
| Спільний контракт для всіх видів зброї | `IWeaponBehavior` | інтерфейс |
| Базова ігрова сутність | `Character` | абстрактний клас |
| Персонажі | `Knight`, `Mage`, `Archer`, `Rogue` | конкретні класи |
| Види зброї (стратегії) | `SwordBehavior`, `BowBehavior`, `StaffBehavior`, `DaggerBehavior` | конкретні класи |

Разом: **1 інтерфейс + 1 абстрактний клас + 8 конкретних класів**.

Діаграму класів дивись у `docs/class-diagram.png`, повний опис — у звіті
`docs/report.docx`.

## Як запустити

Потрібен встановлений .NET SDK.

```bash
cd src
dotnet run
```

Програма створює чотирьох персонажів з початковим озброєнням, виводить їх
атаку, після чого демонструє зміну зброї під час гри (`SetWeapon()`) для
лицаря та мага.
